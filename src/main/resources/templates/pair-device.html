📚 Integration Examples

📱 OwnTracks (iOS/Android)

Mode: HTTP
Endpoint: https://nomad-3m8a.onrender.com/api/devices/YOUR_ID/location
API Key: YOUR_KEY

🔧 curl Command

curl -X POST "https://nomad-3m8a.onrender.com/api/devices/ID/location?apiKey=KEY" \
-H "Content-Type: application/json" \
-d '{"latitude":40.7128,"longitude":-74.006}'

🤖 ESP32/Arduino

HTTP.post("/api/devices/" + deviceId + "/location?apiKey=" + apiKey, "application/json", "{\"latitude\":"+lat+",\"longitude\":"+lng+"}");

🌐 JavaScript (Browser)

navigator.geolocation.getCurrentPosition(pos => {
fetch(`/api/devices/${id}/location?apiKey=${key}`, {
method: 'POST',
body: JSON.stringify({
latitude: pos.coords.latitude,
longitude: pos.coords.longitude
})
});
});
